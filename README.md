# 小黑盒 · 阅读优化

通过 Tampermonkey 优化小黑盒社区首页、具体社区列表页与帖子详情页的阅读排版。当前稳定版 **1.3.0**，支持图片、视频、信息密度、排版、主题和专注模式的自定义。

**[点击安装稳定版](https://raw.githubusercontent.com/Haorain-Li/xiaoheihe/main/xiaoheihe-reader.user.js)**

## 安装和升级

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开上面的安装链接，在扩展安装页确认安装。若显示源码，可新建用户脚本，复制文件全部内容并保存。
3. 刷新 [小黑盒社区首页](https://www.xiaoheihe.cn/app/bbs/home)，使用右下角「阅读设置」。

从仓库旧脚本 `黑盒油猴侧边栏关闭.js` 迁移时，先在扩展中停用旧脚本再启用新版，避免两份样式互相覆盖。旧文件保留作历史参考。新版不删除登录、举报或确认弹窗，也不改动图片查看器和评论编辑器。

从阅读版 1.0.0 / 1.1.0 / 1.2.0 升级时，会沿用原有设置，为新增选项补上默认值。脚本提供更新地址，可由 Tampermonkey 检查更新。

具体社区页也使用同一套设置，例如 [社区 235709](https://www.xiaoheihe.cn/app/topic/link/235709)。字号、摘要、缩略图、视频尺寸、显示开关、阅读预设与主题都会生效；专注模式隐藏该社区的右侧信息和推广区域，保留综合、分类及排序操作。

## 功能

| 设置 | 效果 |
| --- | --- |
| 字号、行距 | 10–40px、1–3 倍行距 |
| 阅读宽度 | 360–2400px，实际宽度受浏览器窗口限制 |
| 帖子上下留白 | 0–64px，可调整浏览密度 |
| 列表摘要行数 | 1–20 行，首页及社区列表共用，开启摘要展开后不受此限制 |
| 列表缩略图 | 48–320px，每帖预览 1–12 张；可完整显示或填满方格 |
| 正文图片最大宽度 | 120–2000px |
| 正文图片最大高度 | 80–1600px，保持原图比例 |
| 封面 / 轮播高度 | 100–1000px，图片保持比例显示 |
| 视频预览尺寸 | 最大宽度 120–1600px、最大高度 80–900px |
| 媒体开关 | 可关闭尺寸优化，或分别隐藏帖子图片与视频 |
| 显示预设 | 紧凑浏览、舒适阅读、宽屏展示；随后仍可单独调整 |
| 主题 | 原站配色、护眼纸色、深色阅读 |
| 专注模式 | 隐藏右侧推广、热门社区和推荐区域 |
| 列表摘要展开 | 可展开网页已经提供的摘要 |
| 社区入口 | 可隐藏首页社区快捷入口 |
| 评论字号 | 可同步正文设置，也可保留原站大小 |
| 停用和恢复 | 设置面板中停用优化，或恢复默认设置 |

默认使用 18px 正文、1.85 倍行距、820px 阅读栏和护眼纸色；列表缩略图为 120px、每帖最多预览 3 张；正文图片最大 520×420px，封面 / 轮播高度 320px，视频预览最大 420×280px。

设置面板分为「图片与视频」「排版与信息密度」「阅读选项」，所有数值同时支持滑块与直接输入。输入后按 Tab 或移开焦点提交，超出范围时自动校正。预设仅改变排版与媒体设置，保留主题、专注模式、摘要展开等阅读选项。点击「紧凑浏览」可快速缩小图片并减少留白。

`Alt + R` 打开或关闭设置，在设置面板内按 `Esc` 关闭。编辑评论时不会抢占快捷键。深色主题主要覆盖阅读区域，导航和部分站点组件保留原样。

正文长图按最大宽高等比缩小，点击图片使用网站的原图查看功能。只有列表缩略图的「填满方格」选项会裁切预览边缘。预览数量限制只是隐藏部分缩略图，不删除原图或修改站点数据；关闭「自定义媒体尺寸」后恢复原站媒体排版。「显示帖子视频」只控制显示，已经播放的视频应先暂停再隐藏。

展开摘要只解除网页已有文字的行数限制，完整帖子仍需打开详情页；脚本不绕过登录或访问权限。

## 稳定性改进

- 多标签页同步设置，保存时合并本标签页改动的字段，减少旧页面覆盖新设置的问题。
- 设置校验范围、类型和步长；存储异常时保持当前阅读功能，提示保存失败并在后续操作时重试。
- 适配无刷新路由跳转、延迟挂载和 `body` / 样式节点重建。页面结构无法识别时暂停排版覆盖。
- 重新初始化会清理旧实例的事件、菜单、存储监听和计时器，避免越用越多。
- 动态帖子通过 CSS 自动应用样式；后台标签页暂停 URL 轮询，支持浏览器前进后退缓存恢复。
- 排版覆盖可撤销，不删除页面数据，不主动发起网络请求。用户脚本管理器检查更新时会访问本仓库。

字段合并能减少不同设置之间的冲突，但用户脚本存储没有跨标签页原子事务；几乎同时修改同一项设置时，后一次保存生效。

## 适配范围

- `https://www.xiaoheihe.cn/app/bbs/home`
- `https://www.xiaoheihe.cn/app/topic/link/社区编号`，包括用户提供的社区 `235709`，不限于这一个编号。
- `https://www.xiaoheihe.cn/app/bbs/link/帖子编号`
- 同域的 `/bbs/home`、`/bbs/link/帖子编号` 路径，以及不带 `www` 的域名。

设置仅在这些阅读页面生效，iframe 不运行脚本。`/app/topic/game/…` 游戏详情标签页共用了社区容器，但不属于当前阅读适配范围，切换到该页会恢复原站排版。选择器依据 2026-10-14 读取的网页 1.2.42 编写。网站改版后可能需要更新选择器。

## 验证和开发

需要 Node.js 和 Playwright Chromium：

```sh
npm install
npx playwright install chromium
npm run check
npm test
```

可用 `BROWSER_EXECUTABLE_PATH` 指定本机 Chromium / Chrome 路径，或用 `PLAYWRIGHT_MODULE_PATH` 指定已安装的 Playwright 模块目录。

回归测试通过自建夹具覆盖：首页 / 社区 / 帖子详情之间的无刷新跳转、不同社区切换、社区延迟挂载、侧栏布局、主题与分类 / 排序按钮，以及缩略图尺寸和数量、图片长宽比、媒体尺寸和隐藏开关、数值输入、显示预设、表情与原图查看器不受影响、设置保存、停用恢复、动态帖子、窄屏、键盘交互、重复初始化、节点重建、存储失败、多标签页同步及缓存恢复。浏览器测试拦截全部网络请求，不使用个人浏览器配置或账号。

本地另使用已下载的站点原始 CSS 验证了基础排版；尚未完成真实登录页面及真实 Tampermonkey 扩展集成测试。夹具通过不代表网站未来版本必然兼容。
